Floti

Your coding agents, on every computer you have, in one window.

  • Sessions outlive the window

    A small host on each computer holds every session. Close the window, or let it crash, and your agents keep working. Open it again and they are where you left them.

  • Every computer in one window

    This PC, a server you reach over your own SSH and each WSL distro, side by side. There is no account and no service in between: your login is the access.

  • The agent's own terminal

    Claude Code runs in its real terminal interface. Floti passes every key and byte through and draws nothing over it.

  • Agents that run agents

    A session can start its own child sessions, hear what they report and stop them, each in a terminal you can watch.

Install
